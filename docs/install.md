## Installation

Overtone can be installed with pip as shown below   

```bash
pip install overtone-vpt2
```

or the latest version from GitHub

```bash
pip install git+https://github.com/thequantumchemist/overtone.git
```

`overtone` requires Python 3.11 or later and has the following dependencies

- `numpy`
- `scipy`
- `ase` (3.23 or later)
- `pydantic`
- `rich` 
- `matplotlib`

Optional extras are `cluster` (shephex),`falcon` (falcon-md), `tutorial` (tblite) and `test`. See the
[manual](manual.md#1-installation) for details and the development install.
